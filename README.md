# CupertinoSliverNavigationBarApp

An iOS-style navigation bar that integrates smoothly with scrollable content and collapses dynamically as the user scrolls.

## Run Instructions

1. Ensure Flutter is installed
2. Run `flutter pub get` to install dependencies
3. Run `flutter run` to start the app

## Three Key Properties

**largeTitle**: Displays the large, prominent title when at the top of the scroll view that collapses into a smaller title when scrolled.

**backgroundColor**: Sets the background color of the navigation bar, affecting the visual contrast and feel.

**trailing**: Displays a widget (e.g., icon or button) on the right side of the navigation bar for actions like adding items.
